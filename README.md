A program that writes exactly one letter to `/output/entry.txt`: **A for coffee**. No word, no explanation, no punctuation. Coffee wins the pick because the morning-coffee ritual — first cup before anything else works, caffeine as a personality — is more vivid, funnier and truer than tea.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
